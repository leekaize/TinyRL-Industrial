# Literature snapshots

One file per paper, built from [`_template.md`](_template.md). Anyone (or any
LLM) can read a single file to get that paper's concepts, methods, snapshot
and schema implications without leaving the repo.

Conventions:

- Filename: `<first-author>-<year>-<short-slug>.md`
- Workflow: read paper → copy `_template.md` → fill all sections → tick Status
- Analytical map lives in [`RESEARCH.md` § Literature anchors](../RESEARCH.md#literature-anchors);
  this index only tracks reading status
- Standards (IEC 63278, IEC 62541, OASIS MQTT) have no snapshot files
