# Design decisions

One entry per "why did we build it this way". Rows are never deleted in the repo file; new decisions are appended; regrouping for clarity is fine. This page mirrors `RESEARCH.md`'s design-decision table (2026-11-19 through 2026-11-22).

| Decision | Rationale | Alternatives rejected |
|----------|-----------|----------------------|
| Settle gate v2: per-feature fast/slow motion EMAs, slow EMA floored at CAL units, all-feature veto + 8-step dwell (2026-11-19) | the scalar gate let one noise-dominated feature flap the whole vector, and a noise lull inside a transition read as stabilized; the floor is the per-step-difference noise bound | quorum calm (a single-feature fault onset must still unsettle), fixed seconds (not self-calibrating) |
| Asks mature at ASK_MIN_BATCH = 15 settled samples; `unidentified` before `unknown` (2026-11-19) | a label is built from the stored batch; asking at episode-open (n=1) stored mostly transition noise and burned the operator's attention; maturing states keep re-identifying, so states that resolve into known conditions never ask | immediate asks (bench 2026-11-19: 1-sample batches), labeling live episodes only |
| Quiet is POSITIONAL, over ANY known condition (Schmitt latch: in at QUIET_Q, out at MATCH_Q; 2026-11-19) | a named condition recurring is not news, normal OR fault; score-gated quiet broke twice: re-testing the tight radius every step flickered, and a known state's score is not stationary across training eras (stopped score rose 1.2 -> ~6 after the speed states were learned) | score-band alarm thresholds on matched states (the outlier gate froze the band at the commissioning level and the first post-training visit alarmed forever); fault-kind never quiet (made every recognized fault re-alarm per visit) |
| Per-condition score bands: used for the converged-state LR floor + diagnostics, NOT for alarms (2026-11-19) | the band is a sound "does the net still predict THIS state" signal, so converged entries refine at the floor rate; repeated full-rate entries compounded interference; alarm duty stays positional | band-gated alarms (see row above); no LR floor |
| Centroid refinement on close: NORMAL-kind episodes only | a fault episode's mean folds in the recovery tail before the clear, dragging fault centroids toward the recovered state | refining all kinds (the blob that swallowed neighbouring states) |
| Fault overlays measurable only while RUNNING (generator + truth); stopped = op_stopped whatever is installed (2026-11-19, user decision) | a stopped machine reads exactly like a stopped machine no matter what is installed: the old leak made stopped+phase_loss a spurious state the nodes correctly refused to distinguish | reporting the overlay while stopped (made quiet stopped passes look like missed identifications) |
| Metrics: no accuracy/F1; latency + false alarms + ask economy at deployed theta | accuracy is a function of theta; threshold sweeps need full-series ground truth (Mueller section 3) | point-adjust F1, ROC/AUC over recorded runs |
| ObGD, not MVP histograms | net learns joint one-step dynamics; overshooting bound keeps bursts sane | MVP histograms |
| StreamingOptimizer replaces ObGD (ported 2026-11-03; v2 via `-DMONITOR_USE_OBGD`) | v3 App. A: per-coordinate displacement < alpha, no 1/d shrinkage as nets grow; host-test green at alpha=2e-3, beta=0.99995, lambda=0.8 | keep v2-era ObGD |
| Layer-aware sparse init (global 95% budget + connectivity floor) | v3 App. C: uniform 90% zeroed ALL first-layer weights at fan-in 4 - node booted deaf; the floor guarantees at least one nonzero input per unit | uniform 90% per-layer |
| Schema exposes only site-dependent knobs (theta, labels, phase); streaming self-adaptation stays node-local | Stream-X holds one fixed config across tasks; site-relative values are what only external context supplies | expose all RL parameters; fully static node |
| Stream-TD (prediction branch), not Stream-Q/AC | condition monitoring has no actions to take; detection needs only prediction error | Stream-Q / Stream-AC on the monitor node |
| Bench protocol = streaming evaluation only | Mueller section 3.1: batch benchmarks mislead practitioners; every baseline scores each step with data < t, no retrospective theta/normalizer fit | batch evaluation as in TAD benchmark suites |
| Uplink carries state changes + episode summaries only; never periodic telemetry | Zhou 2022 uplink principle (value of information): transmit task-relevant info, collapse repeats; grep-verified: no periodic telemetry in `nodes/` | periodic MQTT telemetry stream; raw waveform upload |
| Asks = alarm-gated stream-based selective sampling (`condition_id:"unknown"` inside an episode), not pool-based or agent-initiated | Settles 2012 ch. 1-2: oracle cost argues for rare, event-driven queries; Mueller 2025 one-sided feedback makes alarm-gating the natural trigger | pool-based batch label requests; agent pushing unsolicited labels |
| Retention split from relearning: labels/centroids in `/conditions.jsonl`, weights in `/net.bin`, stats+theta in `/model.bin` | Dohare 2024 (Nature 632): retention must not depend on net plasticity; frozen anchored-ratio centroid space + exact post-boot resume keeps labels alive without replay or relearning | replay buffer for old conditions; relearn-from-scratch on reboot |
| Condition matching = per-condition radii (q x the condition's own measured sigma, in anchored log2-ratio decades), not CAL-derived global units | 2026-11-15 bench: stopped-machine CAL gave the drive ~20-decade radii on its dead features (structurally blind to every running state once one was labeled) and the vib 0.15-decade radii on bands whose noise is +/-0.5 decades; a condition's yardstick must be that condition's own noise | single global radius; CAL-only per-feature units |
| Quiet-unmatched conditions are counted node-side, never asked about; alarm-gating stands | Settles 2012 ch. 2.5 myopia: a threshold gate can be confidently blind to whole regions; counting quiet-unmatched steps is the cheap tripwire, while quiet asks would flood the one-sided oracle | gated + quiet asks by default; ignoring quiet drift entirely |
| Label vocabulary is fleet-wide; centroids stay per node | one machine, two modalities: feature spaces are incomparable across profiles, but the NAME of a condition is meaningful to all; each node builds its centroid from its own stored batch | cross-node centroid or means sharing (raw means re-mapped across incomparable spaces would pin centroids at range edges) |
| rel-obs era (`-DMONITOR_REL_OBS`, 2026-11-20): the agent observes anchored-ratio levels instead of frozen z | frozen z pins every running regime at the clamp - one input point, so the Stream-TD surprise cannot discriminate regimes or faults at running states; rel levels restore per-regime stationarity | staying on frozen z (running states indistinguishable); positional latch only |
| Era-locked `MODEL_VERSION` (6 z / 7 rel / 8 cond, 2026-11-21): a model.bin from another era is rejected, forcing fresh commissioning on env switch | the score scale differs per era; mixing eras would compare incommensurable thresholds and silently invalidate stored bands | sharing models across eras |
| GRACE bootstrap (2026-11-20): a freshly named state (score band immature, s_n < 16) is quiet by name; the grace expires OBJECTIVELY when the band matures | the operator's label vouches for the state while the first learning pass converges; without it the alarm flaps while the score crawls across theta; it cannot outlive the band's maturity | permanent quiet-by-name (masks in-radius faults); no grace (flapping during learning) |
| Band feeding: down-only ratchet + era-specific stationarity gate (2026-11-20/21) | the post-label learning transient must not raise the state's own future alarm line; a decay tail feeding the band to the alarm edge masked in-radius faults | feeding on "just below global theta" (matured the band on hovering transients) |
| `RELEARN_FRAC` = 0.7 (bench-tuned 2026-11-21): a matched state ABOVE its gate re-learns at 0.7 of MONITOR_LR | 1.0 burst-thrashed (the leaky-max keeps burst capacity for ~beta^-1 steps); 0.5 damped the landing but stretched an interference heal past 4700 steps | full rate on every re-entry; floor rate only |
| Console `f` grammar patch (2026-11-20): `f normal` / `f fault` are reserved feedback words; `f <label> [normal\|fault]` labels a condition; the second word is the KIND | the old parser took the second word as the action, so `f speed_1 normal` hit the false-alarm path and the label was discarded; there was no console path to a normal-kind condition at all | second-word-as-action parsing (the labelling bug hit on the rig) |
| cond-obs era (`-DMONITOR_COND_OBS`, 2026-11-21): the agent observes per-condition centered residuals, obs = (rel - c_matched)/u_matched; unknown states center on the nearest condition | both earlier representations have a structural miss: frozen z saturates; rel levels interpolate across regimes (a static fault BETWEEN two trained regimes is predicted straight through). In the centered frame every condition's training manifold sits at 0, so an offset is off-manifold no matter which regimes were learned | per-condition nets (60-300 samples per condition is far too little); absolute-level spaces; hand-tuned scaling constants |
| Positional band (2026-11-21): r_agg = sum_f ((rel_f - c_f)/u_f)^2 vs the condition's own Welford band as a SECOND alarm edge at matched states | the one-step predictor converges to IDENTITY in a static regime in any coordinate frame, so a static in-radius offset is invisible to prediction error once settled; the residual sum sees it: quiet steps sit near chi2(nf), a 2.5-sigma-everywhere fault at 6.25*nf | prediction-only detection (structurally blind to static offsets); max-component radius alone |
| Evidence accumulator (2026-11-21): a leaky integrator of each settled step's excess past the active edge, normalized by that edge's own gate; quiet leaks, never resets | 5-consecutive fired on drift-stale bands while single strong evidence was under-used; magnitude-weighted integration separates marginal drift from real faults | m-of-N consecutive breaches (correlated EMA breaches flap); full reset on one quiet step; per-edge independent Schmitts |
| Frame-switch optimizer reset (2026-11-21): a label arriving mid-settled-state rescales the cond input frame -> onWorldChange() (traces + leaky-max dropped), also on direct A->B match changes | the prediction shock of the frame switch poisons the leaky-max and the heal takes thousands of steps; the label lands mid-settled by definition of the ask flow | reset only at settle edges (misses the label-time frame switch); no reset |
| Scale-free band feeding (cond, 2026-11-21): formation phase feeds unconditionally inside the stationarity gate; maturity hands over to the ratchet + outlier gate | the centered frame rescales every regime to its own sigma, so the commissioning floor is meaningless for other conditions; the score-EMA vs raw-surprise agreement is self-referential and uncontaminable | commissioning-floor gate (cross-scale); sr_base_-relative gate (contaminated by the pre-label alarm transient) |
| Research-budget protocol (2026-11-21): a new condition gets 60-300 settled samples on the rig | the product claim must be provable inside the operator's real labelling window | 4000-step learn windows as the product claim (unavailable on the rig) |
| Re-entry grace + score-band recalibration with a geometry guard (2026-11-22): a regime entry to a KNOWN condition with a matured band gets 16 steps of fresh-label protection, and its first matched step in the window recalibrates the score band, only when the position sits inside the condition's own positional band | the regime-entry optimizer reset legitimately changes the net's converged error floor; the geometry guard keeps a fault coinciding with a transition from being absorbed (the suite caught the unguarded version: the in-radius fault was baked into the band) | recalibrating unconditionally (absorbed the in-radius fault, suite-caught); score-band alarms for matched states (rejected 2026-11-19); permanent re-entry latch |

The full table with exact run ids, bench numbers and superseded-experiment rows lives in `RESEARCH.md` (repo). New decisions are appended there first; this page follows it.
